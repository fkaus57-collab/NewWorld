# 뉴월드윈드오케스트라 랜딩 페이지 초안

`index.html`을 브라우저에서 열면 바로 볼 수 있습니다. 설치나 빌드가 필요 없는 HTML·CSS·JavaScript 페이지입니다.

- `index.html`: 6개 구역과 한국어 구조·이미지·링크 주석
- `styles.css`: 공통 디자인, Flexbox, Grid, 모바일 대응, 호버 효과
- `script.js`: 스크롤 등장 효과, 현재 구역 표시, 모바일 메뉴
- `images/`: 기존 제공 로고와 프로필 사진

## 추후 수정할 내용

1. 단체소개·활동 방향은 예시 문구입니다. 대표자 인사말은 제공받은 단체 소개 내용을 바탕으로 다듬어 반영했습니다.
2. 대표 여현석의 프로필 사진은 `여현석_프로필.webp`를 사용합니다.
3. 첫 화면은 `오케스트라_단체사진1.webp`부터 `오케스트라_단체사진3.webp`까지 순환합니다. 모바일에서는 전체 단원이 보이도록 사진을 하단에 원본 비율로 표시합니다.
4. 공연 포스터·일시·장소·프로그램·예매 링크를 공연안내에 추가하세요.
5. 공식 이메일과 YouTube·Instagram 링크를 반영했습니다. 전화번호는 추후 필요할 경우 추가할 수 있습니다.
6. 하단에 사업자등록번호(417-82-82190)·대표자(여현석)·부산 소재 주소를 반영했습니다.

외부 라이브러리, 외부 폰트, 방문자 정보 수집 기능은 없습니다. 운영체제의 모션 줄이기 설정을 지원하며 JavaScript가 꺼져 있어도 본문을 볼 수 있습니다.

## 웹용 이미지

사진과 로고는 WebP 형식으로 최적화했습니다. 이미지 전체 용량은 약 28.2MB에서 4.6MB로 줄었습니다.
단체사진은 가로 2560px, 프로필은 세로 1800px, 포스터는 세로 3600px이며, 리플릿은 기존 해상도를 유지합니다.
QR 코드는 원본 픽셀을 유지하는 무손실 WebP, 파비콘은 64×64 PNG입니다. 기존 SVG 아이콘도 유지합니다.
HTML의 이미지 주소와 확대 보기 링크는 웹용 파일을 가리킵니다. 인쇄 등에 필요한 변환 전 원본은 Git의 이전 커밋에서 복구할 수 있습니다.
